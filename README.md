# WiFi 防御与安全教育工具

这是一个**完全离线**的本地安全教育应用，用于评估自有 WiFi 密码强度、演示认证失败的限速与锁定策略，并保存不含敏感信息的本地审计记录。

> **安全边界：** 本项目不扫描无线网络、不读取无线网卡、不抓包、不尝试认证、不发送网络请求，也不存储用户输入的密码。它不能用于连接、测试或访问任何真实 WiFi 网络。

## 功能

| 模块 | 作用 | 数据范围 |
|---|---|---|
| 密码强度评估 | 根据长度、字符多样性与常见弱模式提供本地启发式建议 | 密码只在内存中用于一次评估，随后清空 |
| 认证策略模拟 | 演示失败阈值、时间窗口与锁定时间的防御性策略 | 仅接受用户手动触发的合成成功/失败事件 |
| 本地审计日志 | 以 JSONL 格式保存合成事件和策略变更 | 不保存密码、无线网卡、BSSID、SSID 或网络流量 |

## 运行

本工具只使用 Python 标准库，需 Python 3.11 或更高版本。Windows 与 macOS 的常规 Python 安装通常已包含 Tk；在 Ubuntu/Debian 上如缺少图形模块，请先安装 `python3-tk`。

```bash
sudo apt install python3-tk  # 仅 Ubuntu/Debian 且缺少 Tk 时需要
python3 wifi_crack_tool.py
```

本地审计日志默认保存到运行目录下的 `audit_logs/wifi_defense_audit.jsonl`。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

## 设计说明

认证策略模拟器维护的是**进程内的合成状态**。在达到失败阈值时，它只会在本地演示“锁定”结果，并记录对应审计事件；它不会对任何真实网络、设备或服务实施限制。实际生产环境应由路由器、身份提供方或网络访问控制系统执行限速和锁定策略。

## 迁移说明

此分支移除了原有的 WiFi 扫描、连接、密码本、异步破解、断点续传和网络相关依赖。历史版本中的网络攻击功能不再是本分支项目的一部分。
